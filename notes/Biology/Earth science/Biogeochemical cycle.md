# Nitrogen cycle


- **nitrogen fixation** (קִבּוּעַ הַחַנְקָן, קְשִׁירַת חַנְקָן)
- **ammonification** (אִמְנוּן, הֲפִיכָה לְאָמוֹנְיָה, אָמוֹנִיפִיקַצְיָה) – "The formation of ammonia or its compounds from nitrogenous compounds, especially as a result of bacterial decomposition." (Wiktionary)


- **nitrification** (חִנְקוּן, הֲפִיכָה לְחַנְקָה, נִיטְרִיפִיקַצְיָה)
	- **ammonia oxidation** (or **nitritation**)
		- $\ce{\underset{ammonium}{ 2NH4+ } + 3O2 -> \underset{nitrite}{ 2NO2- } + 4H+ + 2H2O}$
		- $\ce{\underset{ ammonia }{ 2NH3 } + 3O2 -> \underset{ nitrite }{ 2NO2 }- + 2H+ + 2H2O}$
	- **nitrite oxidation** (or **nitratation**) 
		- $\ce{\underset{ nitrite }{ 2NO2 }- + O2 -> \underset{ nitrate }{ 2NO3- }}$
- **denitrification** (נְטִילַת-חִנְקוּן, דֵּנִיטְרִיפִיקַצְיָה)
	- $\ce{NO3^- -> NO2^- -> NO -> N2O -> N2}$
- **nitrogen assimilation**
